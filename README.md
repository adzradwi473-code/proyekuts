# BorneoDance Culture

Repositori ini berisi kode sumber lengkap untuk proyek **BorneoDance Culture**, sebuah ensiklopedia digital dan direktori interaktif yang menampilkan ragam seni tari tradisional dari berbagai provinsi di pulau Kalimantan. Proyek ini dikembangkan untuk memenuhi penugasan pembuatan web modern berbasis HTML5, CSS responsif, dan logika JavaScript interaktif.

## Fitur Utama
- **Arsitektur Multi-Halaman**: Terdiri dari halaman Beranda, Katalog Tari, Halaman Detail Tarian, dan Pendaftaran Workshop.
- **Pencarian & Filter Wilayah**: Memungkinkan pengguna mencari tarian berdasarkan nama serta memfilter berdasarkan wilayah provinsi (Kalimantan Selatan, Kalimantan Timur, Kalimantan Tengah, Kalimantan Barat, Kalimantan Utara).
- **Sistem Ulasan & Komentar Interaktif**: Pengunjung dapat memberikan ulasan serta menghapus komentar yang telah dikirimkan secara *real-time* dengan dukungan penyimpanan browser (*Local Storage*).
- **Formulir Pendaftaran Workshop**: Dilengkapi validasi interaktif dan notifikasi pop-up modern menggunakan pustaka SweetAlert2.
- **Desain Responsif**: Tampilan antarmuka yang optimal dan adaptif di berbagai ukuran layar perangkat.

## Struktur Direktori Proyek
proyekuts/
index.html        # Halaman Beranda utama
katalog.html      # Halaman direktori dan pencarian tarian
detail.html       # Halaman informasi detail tarian & ulasan
pendaftaran.html  # Halaman formulir pendaftaran workshop
style.css         # Berkas gaya tata letak & tema visual
script.js         # Logika interaktif, data array, dan DOM manipulation

## Cara Menjalankan Proyek Secara Lokal
1. Pastikan Anda telah mengunduh atau mengklon repositori ini ke komputer Anda.
2. Buka folder proyek menggunakan teks editor seperti **Visual Studio Code**.
3. Jalankan proyek menggunakan ekstensi **Live Server** di VS Code atau buka berkas `index.html` langsung melalui peramban web (*browser*).
